# MAM API Allowlist

The **only** MyAnonamouse endpoints this app may call. Source: MAM API Documentation (`/api/list.php`), as copied by Raygan on 2026-11-21. Claude Code must not open or fetch that page; if something isn't covered here, stop and ask Raygan.

`mam.py` enforces this list in code. Any request to an endpoint or parameter not listed here must raise `MamEndpointNotAllowed` and must not be sent.

Authentication for every call: a `mam_id` session cookie generated by the user in Preferences → Security. Never a username/password, never a login flow.

No rate limits are given in the documentation copied so far. Until that changes, use the conservative limits in `docs/ROADMAP.md`.

## 1. Torrent Search (JSON): `/tor/js/loadSearchJSONbasic.php`

**Listed in API docs:** yes. "main site search, returning json results (instead of html)."

Accepts POST (`application/json`, `application/xml`, `multipart/form-data`, `application/x-www-form-urlencoded`) or GET. The app uses **POST JSON**.

### Allowed top-level parameters

| Param | Use in app | Notes |
|---|---|---|
| `tor` | always | Required. Object; allowed keys below |
| `perpage` | yes | int, **5–1000** per docs; the app clamps to 5–100 |
| `dlLink` | yes | Returns the per-user `dl` hash (see Download, method B) |
| `description` | no (optional later) | Returns the full description field; large payload, avoid by default |
| `isbn` | optional | Returns ISBN field (often blank) |
| `mediaInfo` | optional | Returns key mediaInfo parts |
| `my_snatched` | optional | Limits results to items the user has snatched. Not needed for normal search |
| `thumbnail` | no | Appears only in the docs' example, not in the parameter table; don't send until confirmed |

### Allowed `tor` keys

| Key | Type | Notes |
|---|---|---|
| `text` | text | Search text |
| `srchIn` | array | Any of: `title`, `author`, `narrator`, `series`, `description`, `filenames`, `fileTypes`, `tags` |
| `main_cat` | array | **`13` AudioBooks, `14` E-Books** (also 15 Musicology, 16 Radio; unused) |
| `cat` | list | Sub-category ids (optional) |
| `browse_lang` | list | Language ids (optional) |
| `searchType` | enum | `all`, `active`, `inactive`, `fl`, `fl-VIP`, `VIP`, `nVIP`, `nMeta` |
| `searchIn` | enum | "list to come" in docs; the example uses `torrents`. Send `torrents` or omit |
| `sortType` | enum | `default`, `titleAsc/Desc`, `fileAsc/Desc`, `sizeAsc/Desc`, `seedersAsc/Desc`, `leechersAsc/Desc`, `snatchedAsc/Desc`, `dateAsc/Desc`, `bmkaAsc/Desc`, `reseedAsc/Desc`, `categoryAsc/Desc`, `random` |
| `startNumber` | int | Pagination offset |
| `startDate` / `endDate` | date | `YYYY-MM-DD` or unix timestamp (start inclusive, end exclusive) |
| `id` | int | Return a single torrent's data |
| `hash` | hex | Look up by torrent hash |
| `browseFlagsHideVsShow` | string | Appears in the docs' example only; send only if needed |

### Documented response fields (useful ones)

`id`, `title` (example output shows `name`; handle both), `main_cat`, `category`, `catname`, `author_info` / `narrator_info` / `series_info` (JSON strings of id→name), `filetypes` (example shows `filetype`; handle both), `size`, `numfiles`, `seeders`, `leechers`, `times_completed`, `added` (UTC), `lang_code`, `language`, `tags`, `free`, `vip`, `fl_vip`, `personal_freeleech`, `my_snatched` (5–20 min update delay), `bookmarked`, `owner`, `owner_name`, `dl`. Top level: `data`, `total`, `total_found`.

Numeric and boolean fields arrive as **strings** in the example (`"0"`, `"13"`); coerce carefully.

## 2. Download Torrent: `/tor/download.php`

**Listed in API docs:** yes. "Requires a valid session cookie."

Two documented ways to get a `.torrent`:

**A. With session cookie** (app fetches the file, uploads to qB):
`GET /tor/download.php?tid=<id>`

**B. Without a cookie, via the `dl` hash** (URL can be handed to qB directly). From the `dlLink` docs: prepend `https://www.myanonamouse.net/tor/download.php/` to the `dl` hash **and append `?tid=<id>`**:
`https://www.myanonamouse.net/tor/download.php/<dl>?tid=<id>`

### Parameters

| Param | Allowed? | Notes |
|---|---|---|
| `tid` | **yes, required** | Torrent id |
| `fl` | **NO, never send** | Spends a freeleech wedge to make it personal freeleech, even on VIP torrents. "Automation users beware, no refunds available." The allowlist guard must reject any URL containing `fl`. If this is ever wanted, it must be an explicit per-click user action with a confirmation dialog, and never available to the scheduler or MCP. |

### Not documented, so not allowed

- `download.php?id=<id>`: the current code tries this as a fallback; remove it.
- `download.php/<dl>` **without** `?tid=`: the current code builds this; it must append `?tid=<id>`.

Anything else on the site, including user-status/profile endpoints, bonus/wedge purchase endpoints, bookmarks, requests, and any HTML page. If a future feature needs one of these, Raygan must first confirm it's in the API Documentation and add it here.
